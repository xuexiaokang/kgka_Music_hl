# 车机磁带形态制作经验总结（续十八 ~ 续四十三）

> 项目：九九音乐 `com.hoilai.mm.music` 车机全屏「磁带」形态
> 技术栈：Android 原生 Canvas（Kotlin）+ Python(Pillow/OpenCV) 资产管线
> 收录：从照片素材到成品 UI 的完整方法论、几何公式、踩坑清单与调试工具链

---

## 一、总体架构：分层静态 + 三层动态

磁带 = **一张壳底图 + 窗内动态层 + 最上层静态窗框**，绘制顺序即物理层序：

```
body（壳底图，含烤死的螺丝/倒角高光/底排孔）
→ marks（中央 6 条白刻度，窗面塑料，叠在磁带之上 ← 与原图一致）
→ 圆形卷盘带包（clipPath 裁剪、随进度缩放、随角度旋转）
→ 白色月牙环（固定半径塑料法兰，只旋转不缩放）
→ 齿轮（原图裁剪孔洞区，随角度旋转）
→ frame（窗口黑框，压最上层，保证窗缘纹丝不动）
```

**铁律**：
- 动态元素永远被窗框压住，裁剪矩形严格等于窗口可视区；
- 刻度/窗框等"塑料件"是静态层，**绝不参与时间计量**；
- 全部贴图走 `drawable-nodpi`，View 内按设计坐标 × HI(=2) 换算，View 尺寸自适应、与密度无关。

## 二、几何公式（真实感核心）

| 元素 | 公式 | 出处 |
|---|---|---|
| 带包半径（面积律） | `R² = FLOOR² + (R_FULL²−FLOOR²)·进度比例` | 真实磁带带速恒定 ⇒ 带长（∝截面积）与时间成正比，**半径不是线性** |
| 带包下限 FLOOR | 左 112 / 右 108 设计px = 白月牙环外缘 +8 | 卷芯永远留一线残留磁带（真实磁带结尾亦然） |
| 白月牙环 | 左 r92-104、右 r81-100，固定半径随齿轮同角旋转 | 实测原图；是齿轮塑料，不算入磁带量 |
| 旋转方向 | 两轴**同为逆时针**（磁带沿窗口底部左→右走带） | Android Canvas 正角=顺时针，故角度取负 |
| 旋转速度 | 45°/s（`positionMs/1000 × 45`） | 视觉适宜值 |
| 盘面黄金尺寸 | `S = min(w,h)·√(φ/(1+φ)) ≈ 0.786` | 面积域黄金分割：盘面面积:留白面积 = φ:1 |

**关键教训**：面积律下带缘在环内爬行阶段（p<17%）右侧"看不见棕色"，必须把可见下限抬到环外缘，否则"开头迟迟不出现、结尾提前消失"（这正是 r=70 旧下限被三轮反馈打回的原因）。

## 三、资产管线（Python 脚本链，全部可重跑）

源照片 960×622 → 一组生成脚本 → `drawable-nodpi/*.png`：

| 脚本 | 功能 |
|---|---|
| `gen_body/frame/...` | 各层切图（body 1920×1244 主档） |
| `gen_ring.py` | 白月牙环：极坐标逐半径镜角平铺，`PHI(r)=min(acos(d_edge/r), asin(win_dy/r))`，θ=0 相位对准月牙亮白中段 |
| `gen_holes.py` | 底排 4 孔打透明（保倒角高光环，LINE_AA+羽化） |
| `fix_reels.py` | 卷盘外带重建：r≥174d 同方位角延展 171d 风纹+径向压暗+alpha 填实（照片带卷只到 172d，外圈是黑底毛边） |
| `fix_realness.py` | 方位向亮瓣低通（σ24° 高斯，blend 85%）+ body 窗内残留刻度清除 + marks 按原图实测重生成 |
| `gen_ladder.py` | 清晰度阶梯 t1-t4（1/8、1/4、1/2、3/4，Lanczos），运行时按 `min(w,h)·0.96/IMG_W` 选档，保证降采样 ≤2 倍（960 源图在 3-12 倍压采样下必糊） |

**通用手法**：
- 贴图瑕疵修图三板斧：**径向统计定位**（逐半径带 lum 中位数/p95）→ **极坐标域滤波/延展** → **alpha 羽化收口**（裁剪线永远落在透明区，RING_CLIP_PAD=4px）；
- 一切"多余白点/黑斑"先分清三来源：烤死在底图 / 上层渗漏 / 贴图自带，改错层白干。

## 四、进度同步（跨 Dart/原生时钟）

- Dart：缓冲期时钟停走（`playing && !isBuffering` 才推进 anchor）；
- 原生：`currentMs()` 钳制不越 `durationMs`；`isCompleted` 时强制 pos=durMs；
- tick 冻结：缓冲期间磁带卷盘与时间文字都不走。
- 磁带角度直接用绝对 `positionMs` 驱动（非累积动画），seek/换歌零漂移。

## 五、交互

- 单击切形态易误触 → **长按**（GestureDetector `onLongPress`，~500ms）切换黑胶/磁带，持久化 `PREF_SHOW_CASSETTE`；左右滑动切歌不受影响。
- 横屏高分屏内容偏小 → **自动密度归一**：总缩放 = 用户档位 × (短边逻辑尺寸/720dp)，原生页 density/scaledDensity/densityDpi 在 buildUi 前统一放大。

## 六、调试方法论（本次战役最值钱的部分）

1. **像素级验证优于目测**：OpenCV 带掩码模板匹配定位磁带（0.94+ 分）→ 扇区射线实测带缘半径 → 与理论公式对比，偏差 5-7px 是贴图暗边的系统内缩，方向一致即可判定通过。
2. **旋转方向判定**：大环带含静态边框不可用；连拍 6 帧 + 只取**齿轮齿槽环带**（黑白高对比）圆周互相关，间隔必须 < 对称周期（6 齿=60°），并做符号自校准（人工旋转 20° 定 CCW 的 shift 符号）。
3. **模拟器分辨率漂移**：MuMu 在 720p/1080p/1440p/竖屏间反复跳变——**每次测量前先 `wm size`**，坐标一律按当前分辨率模板匹配重定位，绝不沿用上次。
4. **am start 直启原生 Activity 会被 Dart 立即收回**：必须走 UI 入口（tap 迷你播放器）。
5. **logcat 被 MESA 高频日志冲掉**：后台 `adb logcat &` 写文件再 grep。
6. **测量读数**：亮度剖面（阈值分级）比网格目测可靠一个数量级；连通域检测先收窄条带避免阴影粘连。
